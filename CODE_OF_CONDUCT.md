# Community conduct

Treat contributors and users respectfully. Welcome questions and constructive disagreement. Review code and ideas without personal attacks.

Harassment, threats, discrimination, doxxing, sharing private information and sustained disruption are unacceptable in repository discussions, issues and pull requests.

Report conduct concerns privately to the repository owner, **@OmmPrakash-tech**, through an available private GitHub channel. If none is available, request one without exposing sensitive details. The maintainer may remove harmful content, restrict participation or block accounts, considering severity and context. Apply these expectations consistently and respect reporter privacy.
